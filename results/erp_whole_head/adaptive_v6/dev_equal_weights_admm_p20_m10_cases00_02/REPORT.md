# 白化后逐通道等权重开发消融

范围：仅使用开发清单中 EEG=+20 dB、MEG=-10 dB 的配置 00（纯表层）和配置 02（纯深层）。原始训练/确认均值、试次基线协方差白化、增益矩阵、源模型和 ADMM 设置完全相同；只把训练数据导出的模态权重改为每个白化通道权重 1。没有读取校准集或验证集，也没有选择决策阈值。

统计依据：EEG 和 MEG 分别白化后，每个保留通道的训练均值噪声方差约为 1；独立高斯通道的联合似然对应逐白化通道等权。这个依据只说明消融合理，不预先保证定位更好。

| 病例 | 权重 | H1 An_cal_AUC | H1 An_auc | 分层 An_auc | SD / DLE | 幅度 TP / FP | prediction T | partial score |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 纯表层 00 | 现行 `[1, 0.0367]` | 0.682006 | 0.988409 | 表层 0.988518 | 表层 11.101 / 27.055 mm | 0 / 1 | -0.214097 | -0.323368 |
| 纯表层 00 | 逐通道等权 | 0.682454 | 0.988431 | 表层 0.988540 | 表层 11.039 / 27.055 mm | 0 / 1 | -0.108732 | -0.217712 |
| 纯深层 02 | 现行 `[1, 0.1095]` | 1.000000 | 1.000000 | 深层 1.000000 | 深层 0 / 0 mm | 1 / 0 | 0.252751 | 0.530490 |
| 纯深层 02 | 逐通道等权 | 1.000000 | 1.000000 | 深层 1.000000 | 深层 0 / 0 mm | 1 / 0 | 0.093739 | 0.316862 |

两例的现行与等权 H0/H1 都数值收敛，完整 H0/H1 指标见 `metrics.csv`。等权没有实质提高 AUC、SD 或 DLE；纯深层确认分数反而降低。因此不把等权替换为下一版默认算法，也不继续扩展这个消融。

纯表层病例的两个独立确认分数在两种权重下都为负，方向上支持“不报深源”；旧的 0.14 深层/全局幅度比规则却在两种权重下都误报。这再次说明 AUC 和幅度阈值不能替代独立的深源存在性判定。上述分数尚未校准，不能据此宣称假阳性率。
