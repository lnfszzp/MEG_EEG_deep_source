# v5 共线惩罚 + 稳定多轮 MM：提前终止

本目录是有标签开发探针的失败记录，不是完整实验，也不能用于正式验收。使用冻结的四病例 manifest、trial covariance、excess score 和 `V5_ALIAS_MM_PROBE.md` 中的全部设置；相对上一轮唯一代码变化是 ADMM 的 rho 只在首个凸代理中自适应，后续 MM 轮固定。

| 病例 | 真值 | excess | H0/H1 收敛 | H1 外层轮数 | H1 最终 gap |
|---|---|---:|---|---:|---:|
| 00 | 纯表层 | 1.336769 | True / True | 5 | 0.0000225 |
| 02 | 纯深层 | 0.000000 | True / True | 3 | 0.0000000 |

- 数值修复有效：case 00 的 H1 从上一轮 `42000` 次仍失败，变为 5 轮固定点收敛；case 02 的 H0/H1 也都收敛。
- 科学条件已不可满足：预声明要求 `max(T00,T10) < min(T02,T04)`，但已观察到 `T00=1.336769 > T02=0`。无论剩余两例为何值，严格分离都不可能成立，因此程序刚进入 case 04 即被人工中止。
- case 02 的 H0/H1 confirmation loss 完全相同（均为 `1170.287100`），H1 最终 active rows 为 0；共线惩罚把低低 SNR 的真深层证据也压成了零。

结论：固定 rho 解决了数值收敛，但无倍率的 VIF 共线惩罚不能解决低低 SNR 的深浅层联合可辨识性。不得从本目录重新选择阈值或宣称深层检测改善。
