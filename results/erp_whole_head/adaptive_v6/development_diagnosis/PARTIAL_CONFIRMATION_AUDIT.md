# 独立确认部分回归审计

审计对象：`candidates/oaster_partial_confirmation.py`。本审计只检查代码、公式和合成边界；未读取校准集或验证集结果。

## 结论

这个量可以作为**训练选点后、确认集上的单个深方向嵌套回归统计量**。它不是未校准的深源概率，也不是严格的样本外预测误差。最终判决必须用事先冻结、与待测纯表层病例可交换的纯表层校准来定阈值。

未发现真值泄漏：浅层支持来自训练 H0，深点来自训练 H1；函数没有接收真值、源坐标或病例标签。确认数据只重新估计 nuisance 和一个深方向的时间系数，不返回或替换训练得到的源定位结果。

## 正确的部分

- 令 `U` 为训练 H0 支持的加权导联场正交基，`d` 为训练 H1 深点导联场在 `span(U)` 正交补中的单位方向。确认数据增加的是固定的一个空间方向；因此空间增量自由度为 1，时间增量自由度为保留的平滑基数 `r`。`nuisance_rank` 不应再次从该增量自由度中扣除。
- 数据和导联场先用同一个试次基线白化器变换，再同乘训练数据确定的 EEG/MEG 模态权重。这里是白化加一次模态加权，并非把同一个权重重复施加两次。确认集没有参与白化器、模态权重、浅层支持或深点的选择。
- 对单位方向投影后的基线样本方差使用 `B-1` 分母是正确的。基线均值被减到活动窗后，第 `k` 个时间基的方差增加 `s_k²/B`，代码中的 `sum(s_k²)/B` 修正正确。
- nuisance 与深方向的系数都在确认集上拟合，因而 `improvement` 一定非负。这是嵌套回归的组内拟合增益，不是确认集上的固定预测增益。只要整条打分流程在纯表层校准前冻结，并且校准病例与目标病例可交换，经验校准会同时覆盖这 `r` 个时间系数的组内拟合偏差和训练阶段的候选选择。

## 冻结前必须处理或明确声明的问题

1. **零训练支持被静默解释成全皮层支持。** 当 H0 的基线校正活动幅度全为 0 时，`surface_peak == 0`，条件 `amplitude >= 0` 会选择全部皮层点；后面的空支持 fallback 实际不可达。应显式拒绝“训练 H0 没有活动支持”，或者明确定义空 nuisance 模型，不能把它变成全皮层模型。
2. **零深层训练候选被静默解释成第一个深点。** 当 H1 的所有深层幅度均为 0 时，`argmax` 返回第一个深点，但训练并未选择任何深候选。应显式返回“无训练深候选/不报深源”或抛出可识别错误。
3. **`support_fraction=.1` 与既有指标规则语义不同。** 当前代码按幅度选择 `amplitude >= 0.1 * peak`；`benchmark.metrics.evaluate_estimate` 的既有参数是 `support_energy_fraction=.1`，等价于幅度大于约 `0.316 * peak`。如果 10% 幅度是有意让 nuisance 更完整，应改名并写明，不应声称与既有 10% 能量规则一致。
4. **`-1` 后的零假设均值并非精确为 0。** 若基线噪声为时域独立高斯，样本方差与活动投影独立，则

   `E[improvement / expected_noise - 1] = 2 / (B - 3)`，`B > 3`。

   原因是分母用了估计方差，逆卡方期望不等于逆期望。固定 `B` 下这是全体分数相同的正仿射偏移，不影响经验秩校准；但元数据应称“以基线方差归一化的参考比”，不能称严格零均值统计量。若需要精确零均值，可在比值上乘 `(B-3)/(B-1)`，同时要求 `B > 3`。
5. **近共线只做了机器精度检查。** `conditional_gain_fraction` 极小时，单位化会把几乎不可辨识的深方向变成正常强度的检验方向。机器精度阈值只能防数值除零，不能保证空间可辨识性。若以后增加可辨识性门槛，数值必须在校准前固定，不能看验证真值后调整。
6. **纯表层校准并不自动带来 5% 总体假阳性保证。** 它只能在打分流程完全相同且校准与目标纯表层病例可交换时给出秩校准解释。源位置选择规则、表层源数、SNR、噪声协方差或预处理分布不同都会破坏该解释；有限开发病例的分离也不能替代冻结后的校准和一次性验证。

## 最小验证

现有候选与预测评分测试合计 8 项通过。仍需补两个边界测试：H0 活动幅度全零、H1 深层活动幅度全零。两者应验证明确的“不可打分/不报深源”行为，而不是接受任意皮层支持或任意深点。
