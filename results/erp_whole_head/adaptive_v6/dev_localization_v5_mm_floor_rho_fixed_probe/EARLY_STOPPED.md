# v5 稳定 bounded-MM 基线：提前终止

本目录是有标签开发探针的失败记录，不是完整实验，也不能用于正式验收。它复用冻结的四病例 manifest 和 `V5_MM_FLOOR_PROBE.md` 设置；相对旧探针只修正了 ADMM 在后续 MM 轮的 rho 振荡，没有启用深浅共线惩罚。

| 病例 | 真值 | excess | H0/H1 收敛 | H1 外层轮数 | H1 最终 gap |
|---|---|---:|---|---:|---:|
| 00 | 纯表层 | 1.600049 | True / True | 5 | 0.000883 |
| 02 | 纯深层 | 0.314586 | True / True | 4 | 0.000659 |

- 两例的四个拟合均达到预声明数值容差，说明此前的未收敛已经由 rho 修复解决。
- 科学条件仍已不可满足：`T00=1.600049 > T02=0.314586`，所以 `max(T00,T10) < min(T02,T04)` 不可能成立；程序刚进入 case 04 即被中止。
- case 00 的 H0/H1 loss 为 `1310.430765 / 1188.653982`；case 02 为 `1170.287100 / 1149.704914`。纯表层病例从联合模型获得的 held-out 改善反而远大于真深层病例。

结论：当前失败不是共线惩罚独有，也不是剩余数值不收敛；核心是 H0 皮层模型误差在独立 confirmation 中可重复，预测增益把它误当成深层证据。下一版应改变深层证据的构造，而不是继续调深层惩罚倍率或旧阈值。
